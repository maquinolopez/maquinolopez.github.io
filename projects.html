rplum

R package on CRAN

rplum implements the Bayesian 210Pb age-depth model of Aquino-López et al. (2018) in R. It estimates sediment chronologies and their uncertainty from 210Pb measurements and can incorporate radiocarbon and calendar dates. The package was developed with Maarten Blaauw, J. Andrés Christen, Judith Esquivel-Vázquez, and Oscar M. Gonzalez V.

Reference: Aquino-López et al. (2018) .

BSync

GitHub repository

BSync is an R implementation of the Bayesian synchronization method in Aquino-López, Muschitiello, and Osman (2026). It estimates a monotone mapping from the depth or provisional age scale of an input proxy record to the age scale of a reference record. The posterior distribution quantifies uncertainty in the alignment and the resulting chronology.

The model supports alignment to one reference record, a mixture of two reference records, or a reference record with age uncertainty.

Reference: Aquino-López et al. (2026), Environmetrics .

PyPlum

GitHub repository

PyPlum is a Python implementation of the Bayesian 210Pb age-depth model described in Aquino-López et al. (2018). It estimates sediment chronologies from 210Pb measurements and can combine them with radiocarbon and calendar dates. The accumulation model uses an autoregressive gamma process.

Reference: Aquino-López et al. (2018) . For the R implementation, see rplum .

BISCUIT

GitHub repository

BISCUIT (Bayesian Integration of Sequences Using Chronology Intersection Tie-points) is an R implementation for constructing an age-depth model of a paleoclimate record using selected tie-points to a dated reference record. It combines posterior age distributions at the reference tie-points with prior information on sediment accumulation rates and memory. Unlike BSync, BISCUIT uses tie-points selected by the user.

TACO

GitHub repository

TACO (Transitional Analysis through Clymo Optimization) explores a Bayesian extension of the Clymo model for carbon accumulation and decomposition in peatlands. It allows carbon input to vary and uses a weighted transition function to represent changes between peatland carbon dynamics regimes. The repository contains research code, with documentation and a manuscript still in development.

Plum (Beta Version)

GitHub repository

This is an early R implementation of the Bayesian 210Pb age-depth model described in Aquino-López et al. (2018). It depends on Python 2.7 through rPython and was designed for Linux and macOS. For the official R package, use rplum on CRAN .
